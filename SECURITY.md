# Segurança

Não publique tokens, senhas, cookies de sessão, chaves privadas ou dados pessoais em issues públicas. Use os recursos privados de segurança do GitHub deste repositório, se disponíveis, para relatar vulnerabilidades.

Toda autorização deve ser validada no servidor. Não confiar em IDs, cargos, propriedade de itens ou permissões enviados pelo navegador sem conferir sessão e registros persistidos.
